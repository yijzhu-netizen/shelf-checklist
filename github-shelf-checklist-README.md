# The Shelf Checklist — 27 checks before you spend $1 on ads

> A free, public checklist for self-published authors: audit your Amazon
> book page the way a conversion specialist would, *before* buying traffic.
> Maintained by [Inkpot](https://inkpot.si) — the studio behind the free
> [Shelf Score](https://inkpot.si/shelf-score.html) audit tool.

Most "my ads don't work" stories end at the same place: the ad worked,
it delivered a click — **the page lost the sale**. Run these 27 checks
first. Score yourself honestly; under 20, your launch is early.

## Cover (5)
- [ ] Title readable at 120 px wide
- [ ] Author name legible at 120 px wide
- [ ] Looks like a sibling of your subgenre's current top 10
- [ ] Series number visible (if applicable)
- [ ] One focal idea; passes the grid test (paste it among competitors:
      it should belong, and still be findable in 2 seconds)

## Title & subtitle (3)
- [ ] Title doesn't truncate at thumbnail size (ideally 2–8 words)
- [ ] Subtitle carries trope + flavour + series position
- [ ] Heat level or niche named in words readers actually search

## Blurb (6)
- [ ] Line 1 is a hook (collision / question / dialogue / sharp claim),
      not a setting description or a biography
- [ ] 200–400 words, paragraphs of 1–3 lines
- [ ] Nothing revealed past the first act
- [ ] No more than 3 named characters
- [ ] One real proof element (review quote, reader count, series fact —
      never invented)
- [ ] Closing line re-opens a question and names the trope

## Social proof (3)
- [ ] ARC copies out ≥3 weeks before launch (honest reviews only,
      no incentives — ever)
- [ ] Review ask live in the back matter of every earlier book
- [ ] Any earlier book under 3.8★ investigated before buying traffic

## Metadata (5)
- [ ] All 7 backend keyword slots filled with phrases readers type
      (mine Amazon autocomplete, competitor pages, review language)
- [ ] Every metadata phrase defensible in one sentence
- [ ] Categories researched against the top 10; most specific
      honest shelves chosen
- [ ] Description formatted (short blocks, bold only for hook/proof/nudge)
      and re-read on a phone
- [ ] A+ Content live, with real alt text

## Series machinery (5)
- [ ] Series page created; order and numbering verified
- [ ] Book 1's page shows the series strip correctly
- [ ] Back matter stack complete: book 2's actual opening → series list →
      one-line review ask → reader magnet → short author note
- [ ] All back-matter links alive (check quarterly)
- [ ] Book 1 priced as the front door of the series, not for margin
